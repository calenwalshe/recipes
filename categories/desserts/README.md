# Desserts Category Structure

This directory provides a structured way to organize dessert recipes. Each subdirectory helps keep related information together so new recipes can be added consistently.

## Directory Layout

- `recipes/` – Individual dessert recipes stored as markdown files using the shared template.
- `ingredients/` – Reference guides for common ingredients, substitutions, and flavor pairings.
- `techniques/` – Notes on baking or preparation techniques that are reused across recipes.
- `planning/` – Menus, preparation timelines, or entertaining guides featuring dessert lineups.

## Featured Recipes

The `recipes/` folder currently includes:

- [Classic Chocolate Cake](recipes/classic-chocolate-cake.md)
- [Lemon Tart with Buttery Crust](recipes/lemon-tart.md)
- [Strawberry Shortcakes](recipes/strawberry-shortcakes.md)

Use these examples as references when adding new desserts alongside the reusable [`_template.md`](recipes/_template.md).

## How to Add a New Recipe

1. Copy `recipes/_template.md` to a new file named after the dessert, for example `recipes/chocolate-mousse.md`.
2. Complete each section of the template, keeping ingredient measurements consistent (metric and imperial when possible).
3. If a recipe introduces a new technique or ingredient substitution worth referencing later, add a note to the respective directories.

## Tips for Consistency

- Use title case for recipe names.
- Include prep, cook, and total time for every recipe.
- Provide serving size and storage guidance.
- Reference reusable components (sauces, crusts) from other recipes to avoid duplication.

Happy baking!
