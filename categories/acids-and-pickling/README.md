# Acids & Pickling Essentials

This category collects resources for building bright, tangy components that complement dishes across the menu. Use it to track the acids, salts, and spices that support pickling and fermentation projects.

## Directory Layout

- `gear-checklist.md` – Quick reference for the core vinegars, salts, and whole spices you reach for when building brines.

Add additional guides—like brining ratios, fermentation troubleshooting, or flavor pairing notes—as separate markdown files within this directory.
